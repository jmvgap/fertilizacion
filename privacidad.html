Política de privacidad

Calculadora de Fertilización (aplicación para Android y sitio web jmvgap.github.io/fertilizacion).

Vigente desde el 25 de octubre de 2026.

Qué datos se recolectan

Ninguno. La aplicación no recolecta, no envía y no comparte datos personales ni datos de uso. No tiene publicidad, no usa servicios de análisis ni requiere crear una cuenta.

Dónde quedan los datos que cargás

Los ensayos de distribución, los datos de los lotes y los precios de fertilizantes que cargues se guardan solamente en tu teléfono. No salen del dispositivo, salvo que vos decidas exportarlos (por ejemplo, un archivo CSV o un informe PDF) y compartirlos.

Conexión a internet

La aplicación funciona sin conexión. Solo usa internet si tocás "Actualizar precios": en ese momento descarga un archivo con precios de referencia desde GitHub Pages (jmvgap.github.io). Esa descarga no incluye ningún dato tuyo; como en cualquier conexión a un sitio web, el servidor de GitHub puede registrar datos técnicos (por ejemplo, la dirección IP) según su propia política de privacidad.

Permisos

La aplicación solo pide acceso a internet, para la función "Actualizar precios". No accede a la cámara, la ubicación, los contactos ni otros datos del teléfono. Para importar o exportar archivos usa el selector de archivos del sistema, donde elegís vos qué archivo abrir o dónde guardarlo.

Menores

La aplicación es una herramienta técnica agronómica y no está dirigida a menores.

Cambios y contacto

Si esta política cambia, la nueva versión se publicará en esta misma página. El código de la aplicación es libre (licencia GPL-3) y puede consultarse en github.com/jmvgap/fertilizacion; para consultas podés abrir un aviso ("issue") en ese repositorio.
